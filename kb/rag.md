# RAG 检索增强生成

RAG（Retrieval-Augmented Generation）= 先检索，再回答。

为什么需要它：大模型的知识停留在训练截止日，而且会产生幻觉（编造事实）。
RAG 在回答前先从知识库里检索相关内容，让模型基于真实资料作答。

基本流程：
1. 把文档切块，用 Embedding 模型转成向量，存入向量数据库。
2. 用户提问时，把问题也转成向量，按相似度找出最相关的文档块。
3. 把检索结果塞进 Prompt，让模型基于这些内容生成回答。

本项目 kb_search 工具是 RAG 的最小演示：用关键词重合度代替向量相似度，
思想完全一致——先检索相关知识，再让模型基于检索结果回答。
